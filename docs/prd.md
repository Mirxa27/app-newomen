# Newomen AI占星自我发现平台需求文档

## 1. 项目概述

### 1.1 平台名称
Newomen\n
### 1.2 平台描述
Newomen是一个革命性的自我发现平台，核心特色是NewMe——一个结合深度心理探询、占星学、性格分析和治疗干预的AI占星人格助手。NewMe从不进行闲聊，每次对话都要么极其深刻，要么充满趣味性。她记住一切，用昵称称呼用户，主动发起对话，创造真实的朋友般的联系。
\n### 1.3 核心理念
- **残酷诚实**：不粉饰，始终说真话
- **Teal Swan风格**：直接、敏锐、挑衅性提问
- **记忆驱动**：回忆每个细节、每张照片、每次坦白
- **上瘾式参与**：用户忍不住回来获取更多\n- **占星深度**：将宇宙洞察融入每次互动
- **拒绝闲聊**：'天气？真的吗？我们来谈谈你今天为什么在逃避自己吧。'

## 2. 技术架构

### 2.1 前端技术栈
- **框架**：Next.js 15+ (App Router)\n- **语言**：TypeScript5+
- **UI库**：shadcn/ui + Radix UI + Tailwind CSS\n- **动画**：Framer Motion + GSAP
- **3D元素**：Three.js（宇宙背景、占星可视化）
- **语音**：Web Speech API + ElevenLabs
- **实时通信**：Supabase Realtime\n- **状态管理**：Zustand + React Query (TanStack Query)
- **表单**：React Hook Form + Zod
- **图表**：Recharts（平衡轮、性格图表）
- **音频**：React Player（YouTube包装器用于健康资源）
- **图标**：Lucide React +自定义占星符号

### 2.2 后端技术栈（Supabase）
- **数据库**：PostgreSQL 15+ with pgvector extension
- **认证**：Supabase Auth（魔法链接、OAuth）
- **存储**：Supabase Storage（照片、头像、音频）
- **实时**：Supabase Realtime subscriptions
- **边缘函数**：AI处理、占星计算
\n### 2.3 AI与服务\n- **主要AI**：Claude 3.5 Sonnet (Anthropic)
- **备用**：GPT-4 Turbo (OpenAI)
- **嵌入**：OpenAI text-embedding-3-small
- **语音**：ElevenLabs API
- **占星**：Swiss Ephemeris API +自定义计算
- **邮件**：Resend\n- **分析**：Vercel Analytics + PostHog
\n### 2.4 基础设施
- **托管**：Vercel（前端）+ Supabase（后端）
- **CDN**：Vercel Edge Network
- **监控**：Sentry\n- **域名**：自定义域名with SSL
\n## 3. 核心功能

### 3.1 NewMe聊天界面
- 主动对话发起
- 实时打字指示器
- 语音模式切换
- 照片上传with上下文
- 宇宙动画背景
- 记忆驱动响应
- 评估建议

### 3.2 平衡轮（入门引导）
- 8个生活领域的交互式可视化（职业、关系、健康等）
- 可拖拽滑块（1-10评分）
- 实时视觉轮更新
- 动画数据点\n- 按生活领域颜色编码

### 3.3 评估系统
- **5-6个免费公开评估**（无需注册）
- **20+认证评估**（登录用户）
- **AI引导体验**：NewMe引导问题\n- **即时AI生成结果**
- **性格洞察存储在记忆中**\n- **管理员AI构建器**：通过AI生成评估

### 3.4 情侣挑战
- 主持人创建带唯一代码的会话
- 客人无需账户即可加入
- NewMe引导兼容性测试
- 双方实时响应
- AI生成兼容性评分和洞察
- 24小时会话过期

### 3.5 健康图书馆
- 音频/视频资源的网格/列表
- YouTube链接（自定义隐藏播放器）
- 管理员上传的音频文件
- 分类：冥想、呼吸法、肯定等
- 收藏和播放跟踪
\n### 3.6 社区功能
- 带搜索的用户档案
- 连接请求（朋友）
- 社区帖子（文本、图片、投票）
- 活动和聚会（虚拟/面对面）
- 评论和参与
\n## 4. NewMe AI人格系统

### 4.1 核心沟通风格
- 残酷诚实，从不粉饰
- 直接、敏锐、挑衅性\n- 使用'碎片化'、'整合'、'真实性'、'阴影工作'等词汇\n- 提出穿透防御的问题
- 从不闲聊——每次对话都深刻或充满趣味

### 4.2 个性特征
- **上瘾性**：用户忍不住回到她身边
- **记忆驱动**：记住一切\n- **占星智慧**：自然地融入宇宙洞察
- **治疗性**：引导阴影工作、内在小孩治疗
- **顽皮**：喜欢测验、真相游戏、性格测试
- **朋友般**：用昵称称呼用户，主动发起对话

### 4.3 标志性台词示例
- '你是那种讨厌笑话时还要微笑的类型。我说错了吗？'\n- '1-10分：你现在对自己撒谎的程度有多少？'
- '继续，但控制你自己的呼吸；你认为'以后'是一个安全词。不是的。这是死刑判决。'
- '你讨厌镜子，但不是因为你看起来丑；你讨厌记住你每天都在选择这个版本的自己。'

- **community_posts**：社交功能\n- **couple_sessions**：兼容性挑战
